# SnakeCodingClub


Further information about the project can be found in the [Documentation](https://github.com/Alexandre-Gh/Coding-Club-Snake/blob/main/doc/Documentation.md).  
There is also a small tutorial here: [Tutorial](https://github.com/Alexandre-Gh/Coding-Club-Snake/blob/main/doc/IntroductionTutorial.md).  
If you want to see how the finished game looks, Follow the link below:  
https://codingclubs-berlin.github.io/SnakeGame_Completed/



---

## 1. Download the project as a ZIP file

On the repository page:

1. Click the green **Code** button
2. Click **Download ZIP**

Your browser will begin downloading the project.

---

## 2. Locate the downloaded ZIP file

Once the download is complete, find the `.zip` file in your **Downloads** folder.

The file should look something like this:

```text
coding-club-snake.zip
```

---

## 3. Extract the ZIP file

Before opening the project, the archive must be extracted.

### On Windows

- Right-click the `.zip` file
- Click **Extract All**

### On macOS

- Double-click the `.zip` file

### On Linux

- Right-click the `.zip` file
- Choose **Extract Here** or **Extract**

After extraction, a normal folder containing the project files will appear.

---

## 4. Open Visual Studio Code

Launch Visual Studio Code.

---

## 5. Open the extracted project folder

Inside Visual Studio Code:

1. Click **File**
2. Click **Open Folder**

Then:

1. Navigate to the extracted project folder
2. Select the folder
3. Click **Open**

---

# 6 Install the "Live Server" Extension

Click on this link to the page of the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension.

The page should display information about the extension and an install button.

---

## 7. Install the extension

Click the **Install** button on the website.

Your browser may ask for permission to open Visual Studio Code.

Accept the request.

---

## 8. Confirm installation inside VSCode

Visual Studio Code should automatically open on the extension page.

Click **Install** again inside VSCode if necessary.
Once installed, the extension is ready to use.

To use the extension, you have to click on the "Go Live" button at the bottom right of VSCode

---

## 9. Project opened successfully

The project files should now appear in the left sidebar of Visual Studio Code.
You can now begin working on the code.
